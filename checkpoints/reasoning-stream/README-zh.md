# Glaze 0.10.1 思考区显示测试修订 r1

基于官方 v0.10.1，提交 32def585e23f3d55266484ca8076012549260cf9，保留上一版简体中文资源和功能。

## 已确认并修复

官方和汉化版本均可复现：正文中已形成的 <think>...</think> 思考框展开后，下一次流式正文更新会重建 HTML，导致思考框自动关闭。修订版在同一流式回复的累计更新和最后一次更新时保留展开/收起状态；切换到另一条完成的回复变体时不继承旧状态。

## 尚未确认

用户报告“生成中点击思考后，正文进入思考区且没有正常回复”的完整故障尚未复现。模拟独立 reasoning 字段的展开、收起、反复点击、长思考和手机尺寸布局测试中，正文始终与思考分开。不能把本修订描述为已彻底修复该报告。未进行用户真实模型 API 调用或手机实机安装。

- 官方源码复现测试：3 项通过，1 项失败（思考框展开状态丢失）。

- 修改后针对性测试：26 项通过。

- 中文资源检查：4237 个 UI 键、4261 个叶节点；占位符、URL、重复键、帮助结构和英俄原文检查通过。
- JavaScript 语法与 git diff 空白检查通过。

测试文本为合成复现样例，不是用户的实际 API 流记录。
